# 満員電車 — CHAOS LINE

架空の通勤車両に乗客を配置し、ストレスの伝播からトラブルを仕掛けるWeb戦略パズル。通常51種・特殊10種のイベント、5種族と年代、7駅の乗降を扱います。

## 開発

Node.js 24以降を利用します。

```sh
npm ci
npm run dev
```

開発サーバーはポート5173で起動します。既存チェックアウトを使い、タスクごとにworktreeを作る必要はありません。

```sh
npm run check
npm test
npm run build
```

`dist/` に静的サイトを生成します。GitHub Pagesのワークフローは同ディレクトリを公開対象にします。

## 遊び方

待機列の駒を選び、空き区画へ配置します。ストレス80以上の駒は隣接駒へ25を伝えます。伝播で新たに閾値へ達した乗客を含む組合せがトラブルを生み、種類・同時成立・連鎖の深さがカオススコアになります。盤面の色は現在のストレス分布を示します。各停車駅でシードと区間に応じた3つのバフから1つを選べます。効果はその区間に適用されます。目標エリアでトラブルを起こすと400点と次駅の追加移動1回を獲得します。同じ区間の別エリアでトラブルを起こすたびに250点が加わります。同じエリアの通常トラブルは3件目から基本点が40%になります。

全員配置して発車。既存駒の移動は各駅2回、扉際は3人まで。7駅の終着、または混雑率200%で終了します。同じシードは同じ乗客・乗降を再現します。盤面は矢印キーとEnterでも操作できます。

## 設計と素材

ゲームロジックは `src/game/`、画面は `src/main.ts`、音は `src/audio.ts` に分離しています。ルールとイベント条件は `docs/train-plan.md` / `docs/train-events.md`、体験設計は `docs/train-experience.md` に記録しています。

駒のSVGと16bitサンプルベースのBGM・効果音は独自制作です。音の制作と検査記録は `docs/train-audio.md`、音源情報は `public/audio/credits.json` を参照してください。音は最初の操作後に有効になり、音設定からBGM・音量・ミュートを変更できます。

車両寸法、乗客属性の出現率、得点係数はゲーム用の仮定です。現実の車両・路線・人物の性質やトラブル頻度の再現を示すものではありません。外部資料の取得状況は `docs/train-research.md` に記録しています。

## 連鎖演出の設計

『ぷよぷよ』の連鎖では、消去が一段ずつ進み、連鎖数と間隔で勢いが伝わる。『Vampire Survivors』では、広い画面内の反応が重なり、数値や大きな形が注目点を作る。本作では、盤面上の発火→伝播線→成立地点の衝撃波と、HUDの連鎖数・イベント名・加点に応用した。特殊トラブルは金色の菱形と長い表示時間で区別する。既存作品の素材は使用していない。公式ページは環境の接続制限で取得できず、この比較は既知のゲーム表現に基づく。

- [ぷよぷよテトリス2](https://puyo.sega.com/tetris2/)
- [Vampire Survivors（Steam）](https://store.steampowered.com/app/1794680/Vampire_Survivors/)

配置時に採点すると、待機列を並べる途中で連鎖が消費され、取り消しと得点の整合も複雑になる。配置では乗車の歩行とストレス分布を表示し、発車で盤面を確定して連鎖を一括再生する。通常波を短く、イベント波を長く再生して要所を読めるようにする。
