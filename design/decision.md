# デザイン方針（design/decision.md）

## 出発点

| 項目 | 内容 |
|---|---|
| 種類 | 設問に答えて結果を読み、任意で体験する読み物型のWebサイト（静的、日本語） |
| 目的 | 回答者の恐怖傾向を推定して見せる。体験は任意で、先に診断レポートで内容を要約する |
| ユーザー | 一般の成人。スマートフォン利用が多いと想定する。夜に一人で見る場面が多い |
| コンテンツ | 短い設問文、傾向の可視化、日本語の文章主体の体験 |
| 世界観 | 日常の異化・記録。怪談の「聞き取り」と行政文書の無機質さを重ねる |

## 視覚方針：「聞き取り調査票」

設問画面は、役所や研究機関の聞き取り調査票に似せる。恐怖を直接示す記号（血、目、グリッチ）を使わず、事務的な書式の中で言葉だけが少しずつ日常からずれていく。結果の体験では、同じ調査票が劣化し、記入欄が増え、余白が侵食される。UI自体が変質することが演出であり、世界観とモーションの理由になる。

| 要素 | 決定 | 理由 |
|---|---|---|
| 背景 | 紙に近い温かい灰色（#e8e4d8）。体験中は段階的に暗くなる | 純白と純黒を避け、記録媒体の質感を出す。暗転は体験の段階を示す情報になる |
| 文字色 | 青みのない墨色（#1e1d1a） | 背景と同系の色味でコントラスト比を確保する（約13:1） |
| アクセント | くすんだ朱色（#9b2d1c）を押印・進捗・警告にのみ小面積で使う | アクセントは1色。判子の印影の連想で、事務書式に自然に収まる |
| 本文書体 | 明朝系（游明朝、ヒラギノ明朝、Noto Serif CJK JP）、行間1.9 | 文芸・怪談の読み物としての可読性。実行時に外部通信をしないためシステム書体の指定のみ |
| 補助書体 | 等幅（ui-monospace系）、tabular-nums | 設問番号、シード値、記録時刻を桁揃えで示す。書式の無機質さを担う |
| レイアウト | 左に狭い欄外（設問番号・欄名）、右に本文。幅は約38rem、スマホでは欄外が本文の上に回る | 非対称で、書式の「欄」を表現する。カードの積み重ねを避ける |
| 回答の選択肢 | 罫線で区切った6行の一覧（番号付き）。ボタンの塗りつぶしは使わない | 調査票の選択式の再現。タップ領域は高さ48px以上を確保する |
| 質感 | 細い罫線、紙のノイズ（静止画）、体験中のみスキャンノイズ（低速・低コントラスト） | ノイズは世界観のために使う。閃光にならないよう時間変化を1秒あたり2回以下に制限する |
| 角丸 | 使わない（0〜2px） | 書式は直線で構成される |

## モーション

| 場面 | 動き | 目的 |
|---|---|---|
| 設問の切り替え | 0.2秒の不透明度変化 | 次の設問に移ったことを示す |
| 体験の本文 | 行ごとのゆっくりした出現（間は強度とペースで変える） | 時間構造の演出。間が体験の中心 |
| 背景の変質 | 段階ごとに0.8秒以上かけた色と罫線の変化 | 「違和感→確信→侵犯」の進行を示す |
| すべて | `prefers-reduced-motion: reduce` で停止し、段階ごとの静止表示に置き換える | 安全配慮（第8.1節） |

閃光、急な全画面の色変化、点滅するテキストは使わない。

## 採用しなかった案

| 案 | 不採用の理由 |
|---|---|
| 暗い背景＋紫や赤のネオン＋ガラス質カード | 題材から導いた必然性がなく、既視感が強い |
| 血痕・目・グリッチ文字などの記号 | 直接描写を避ける方針と合わない。診断画面が体験の一部のように見えてしまう |
| 常時ダークモード | 夜間の閲覧では暗い画面が体験の演出と区別できなくなる。段階的な暗転の効果も失う |
| 外部Webフォント | 実行時の外部通信なしの方針に反する |

## 状態の設計

| 状態 | 扱い |
|---|---|
| 読み込み中 | 調査票の「用紙を準備しています」表示。失敗時は原因と再読込の案内を同じ書式で出す |
| エラー | データ読み込み失敗は赤い枠でなく、欄外に朱色の注記で示す |
| フォーカス | 2px以上の朱色アウトラインを残す（キーボード操作） |
| 中止 | 体験中は画面上部に「中止して戻る」を常時固定表示する。押下で即座に停止し、レポートへ戻る |

## 受け入れ基準

- 設問画面と結果画面のスクリーンショットで、上記の書式が崩れていないこと（Phase 6で確認）。
- 文字と背景のコントラスト比が4.5:1以上であること。
- 幅360pxで横スクロールが発生しないこと。
- `prefers-reduced-motion` 時に動くものが残らないこと。
