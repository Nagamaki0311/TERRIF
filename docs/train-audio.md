# オリジナル音源と再生設計

2026年11月27日更新。BGMとイベント音は維持し、配置音を空気圧風へ変更。操作音6種を追加し、効果音は14種類。主観的な音質・爽快感の試聴評価は未実施。

## BGM

曲名は「Night Express」。このプロジェクト用に音列と編曲を新規作成した16小節、112BPM、4/4拍子、約34.286秒のループ。既存楽曲や市販ゲームの音源、外部サンプルは使用していない。

リードは息の成分を混ぜたリード楽器風、伴奏は弦風のパッド、減衰のある分散和音、ベース、キック・スネア・ハイハット。前半と後半でオクターブ補強と伴奏密度を変える。複数倍音・微小な揺らぎ・減衰包絡を合成し、22,050Hz・16bit PCMへ量子化してからOgg Vorbisへ書き出した。円環ディレイによってループ境界にも残響を持たせている。

## 効果音と再生

配置・通常連鎖・上昇連鎖・深い連鎖・複数同時・カットイン・特殊成立・最終着地と、操作音6種。金属と木質の減衰共振器へ、低域の胴鳴り、短い擦過音、時間差の和音、左右の短い室内反射を重ねた独自合成で、実物の収録音は使用していない。`scripts/generate-effects.py` が固定シードでSEだけを再生成し、BGMには触れない。生成には既存制作環境のnumpyを使う。ゲーム実行時の依存追加はない。

配置音は0.58秒の「プシュー」を想定。広い帯域のノイズから高いざらつきと低い唸りを除き、18msで立ち上がる空気抜けと、小さな機構の着地を重ねた。実車の録音や電子ビープは使っていない。

| 操作 | 音の役割 |
|---|---|
| 選択 | 短い機構のクリック |
| 再配置 | 空気と機構のスライド |
| 決定 | 小さな二段の金属着地 |
| 戻る・キャンセル | 下がる二段のクリック |
| 表示切替・移動 | 軽く短いスライド。再配置と同素材で速度と音量を変更 |
| 配置不可 | 低い二度の機構音 |
| 発車 | 空気抜けから機構の締まりへ |

`playOperation(kind)`は既存の8声管理を使う。音源読込中の操作と配置は共通で最新1件だけ保持し、1秒以内に読込が終わった場合に再生する。初回に盤面を直接タップして配置した場合も、先行する選択音を重ねず配置音を1回だけ再生する。古い操作をまとめて鳴らさず、`stop()`とミュートで待機中の操作も破棄する。再生開始には従来どおりユーザー操作から`unlock()`を呼ぶ。

連鎖1段目は通常打撃、2〜3段目は上昇和音、4段目以降は低い打撃と上昇和音の組み合わせ。2イベント以上は55ms後に複合打撃、4イベント以上は170ms後にも輪郭のあるアクセントを追加する。特殊成立は1.9秒の余韻を持つ専用音。1波の冒頭は`playWave()`が鳴らし、同じ波の2枚目以降のイベント表示は`playEvent()`で短く区切る。数値の単純なピッチ変更だけに依存せず、重なりと音色で段階を伝える。

`src/audio.ts` の `GameAudio` がローカル音源を読み込む。最初の操作で `unlock()` してBGMを開始する。同じwaveの反応は主音へまとめ、同時イベントと特殊成立に短い追加層を加える。音源15点が揃って初めてreadyとする。全効果音共通の発音管理で同時8声までとし、9声目では最古の効果音を停止する。配置・連鎖・特殊・着地の重なりも同じ制限を通る。BGMのステレオループは別の1ソースとなる。

連鎖中はBGMを約4.3dB下げ、短い時間で復帰する。マスター前にコンプレッサーを通し、初期マスター音量は72%。ミュート、BGMの有効化、全体音量を保存する。音源取得エラーは `unlock()` の例外で呼出元へ返し、再試行できる。`stop()` は予約中の効果音も停止し、次の `unlock()` で再開できる。

## 数値検証

| 検査対象 | 結果 |
|---|---|
| BGMのPCM元音源 | peak 0.820、RMS 0.144、両端差0 |
| 配信用Oggの復号後 | peak 0.785、RMS 0.144、両端差0.0081 |
| 効果音14種 | peak 0.760、RMS 0.080〜0.169、0.14〜1.90秒 |
| ChromiumでのSE復号 | 14点成功、peak 0.721〜0.788（再標本化を含む） |
| 配信用音源15点の合計 | 約1285KiB |

PCM元音源と配信用Oggはフルスケールを超えていない。Oggは非可逆圧縮のため、ループ両端の差が元PCMと異なる。実機でのループ感、内蔵スピーカーでの厚み、耳の疲労、連鎖時の聴き分けは試聴で確認する。生成条件と取得元情報は `public/audio/credits.json` にも記録した。

2026年11月26日検証：生成時に全PCMの有限値・ピーク0.8未満を検査。音声境界のテストで9音源の読込、深度別音色と同時成立の鳴り分け、8声上限、ミュート、予約音を含む停止を確認した。波形の検証は聴覚上の快感や内蔵スピーカーでの音質を保証しない。

2026年11月27日検証：配置音と操作音6種を含む14SEをChromiumで復号し、2チャンネル・ピーク0.8未満を確認。操作ごとの素材、読込中の最新1件のみの再生、1秒経過での破棄、stop中の読込完了後に鳴らないことを音声境界テストで確認。BGMと既存イベント7SEのバイナリに差分なし。主観的な音色評価は未実施。
