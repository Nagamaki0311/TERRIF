# オリジナル音源と再生設計

2026年11月24日。BGMと効果音の実音源を制作済み。主観的な音質・爽快感の試聴評価は未実施。

## BGM

曲名は「Night Express」。このプロジェクト用に音列と編曲を新規作成した16小節、112BPM、4/4拍子、約34.286秒のループ。既存楽曲や市販ゲームの音源、外部サンプルは使用していない。

リードは息の成分を混ぜたリード楽器風、伴奏は弦風のパッド、減衰のある分散和音、ベース、キック・スネア・ハイハット。前半と後半でオクターブ補強と伴奏密度を変える。複数倍音・微小な揺らぎ・減衰包絡を合成し、22,050Hz・16bit PCMへ量子化してからOgg Vorbisへ書き出した。円環ディレイによってループ境界にも残響を持たせている。

## 効果音と再生

配置・連鎖・特殊成立・最終着地の4音は、金属と木質の胴鳴りを想定した減衰共振器と短いノイズ過渡音を独自合成した。実物の収録音を使用したという主張は行わない。

`src/audio.ts` の `GameAudio` がローカル音源を読み込む。最初の操作で `unlock()` してBGMを開始する。同じwaveの反応は主音へまとめ、同時イベントと特殊成立に短い追加層を加える。全効果音共通の発音管理で同時8声までとし、9声目では最古の効果音を停止する。配置・連鎖・特殊・着地の重なりも同じ制限を通る。BGMのステレオループは別の1ソースとなる。

連鎖中はBGMを約4.3dB下げ、短い時間で復帰する。マスター前にコンプレッサーを通し、初期マスター音量は72%。ミュート、BGMの有効化、全体音量を保存する。音源取得エラーは `unlock()` の例外で呼出元へ返し、再試行できる。`stop()` は予約中の効果音も停止し、次の `unlock()` で再開できる。

## 数値検証

| 検査対象 | 結果 |
|---|---|
| BGMのPCM元音源 | peak 0.820、RMS 0.144、両端差0 |
| 配信用Oggの復号後 | peak 0.785、RMS 0.144、両端差0.0081 |
| 効果音4種 | peak 0.593〜0.633、RMS 0.108〜0.130 |
| 配信用音源5点の合計 | 約572KB |

PCM元音源と配信用Oggはフルスケールを超えていない。Oggは非可逆圧縮のため、ループ両端の差が元PCMと異なる。実機でのループ感、内蔵スピーカーでの厚み、耳の疲労、連鎖時の聴き分けは試聴で確認する。生成条件と取得元情報は `public/audio/credits.json` にも記録した。
