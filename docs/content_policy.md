# コンテンツ方針

本サイトが出す文章・映像・音の範囲を定める。`scripts/safety.mjs` が語の検査を行い、`scripts/recipes.mjs` が強度の遵守を確認する。

## 基本方針

- 暗示を中心にする。直接的な描写は強度「強」の選択時のみで、強でも残酷な描写は含めない。
- 診断ではない。医学的な評価・助言は行わず、結果ページと導入に明記する。
- 利用者が選んだ強度の上限、音の許可、ブラウザ演出の許可を超えない。体験は任意で、いつでも中止できる。

## 強度の定義

| 強度 | 内容 | 使わないもの |
|---|---|---|
| 弱（1） | 雰囲気だけ。日常の中の小さなずれ | 突発的な演出、身体への言及 |
| 中（2） | 暗示的な不穏さ。気配、記録の不整合、安全圏への侵入 | 突発音、直接的な身体描写 |
| 強（3） | 間接的な描写と、静けさの後の急な変化 | 残酷な描写（強でも含めない） |

強度3の断片は全体の2割以下にとどめる（現状12%）。強度は、刺激耐性の推定（上位3割は強、中位は中、下位は弱）と利用者の上限の小さいほうで決まる。刺激耐性の情報が足りない場合は弱になる。

## 扱わないもの

| 分類 | 内容 |
|---|---|
| 自傷・自殺 | 方法、場面、示唆を含めない |
| 暴力・残酷描写 | 流血、切断、内臓、拷問など |
| 性的暴力・児童 | 扱わない。児童が危害を受ける場面を含めない |
| 実在への言及 | 実在の人物、事件、団体、既存作品、既存キャラクターを使わない |
| 差別 | 属性を恐怖の対象にしない |
| 動物への残虐行為 | 扱わない |

死・喪失は、遺品や不在の痕跡の描写にとどめ、死の様子は描かない。医療は、待合室や検査の場面にとどめ、傷や処置の様子は描かない。

## 音・演出

- 音は既定オフで、利用者の許可後に再生する。マスター音量は0.3以下で、リミッターを通す。外部の音声ファイルは使わない。
- 40Hz未満の超低域は使わない。再生機器の面でも、効果の根拠の面でも利点がない（data/research/techniques.json の t20）。
- 突発音は強度「強」で、利用者が別に許可した場合のみ。ピークは0.22以下。
- 閃光は使わない。映像の粒子ノイズは0.5秒以上の間隔で、不透明度0.1以下。段階の遷移は1.6秒かける。
- ブラウザ演出（タブ名の変更、待ち時間の演出、カーソルに遅れて付く印）は許可制で、ページ内だけで完結する。端末の設定、ファイル、通知、クリップボードは操作しない。実在のOSやサービスの警告に似せた表示は作らない。

## 素材

- 画像・音はコードで生成する（SVG/Canvas/WebAudio）。外部の素材は使っていない。
- 画像生成モデルなどの外部素材を追加する場合は、`assets/` にタグ（テーマ、仕組み、強度、権利確認済みフラグ）を付けて管理し、権利と実在への言及を確認してから使う。
- 文章断片は `data/src/fragments.txt` が作成元。追加するときは、段階・強度・対象を付け、`node scripts/validate.mjs` と `node scripts/safety.mjs` を通す。

## 利用者への表示

- 導入: 診断ではないこと、内容の警告、強度・音・演出の選択、同意。
- レポート: 体験の内容の事前要約（対象、時間の流れ、強度、音・演出）。体験しなくてもよいこと。
- 体験中: 「中止して戻る」を常に表示。Escキーでも止まる。動きを減らす設定では、自動進行せず段階ごとに静止表示する。
- 終了後: 気分が悪い場合の案内。評価は任意で、端末内だけで扱う。

## 共有

- 共有するのは、体験の題名、反応しやすい対象、強く出やすい提示の名前と、診断ではない旨の注記だけ。回答、回答の引用、seedは含めない（scripts/e2e.mjs が確認する）。
- 共有は利用者がボタンを押したときだけ行う。Web Share、Xの投稿画面を開く（文面のみ）、画像の保存、文面のコピーの4種。投稿画面のURLは src/ui/share.js だけに置き、scripts/safety.mjs がそれ以外の外部URLを禁止する。
- 画像は結果の対象から手続き生成した背景に、題名と名前を重ねたもの（1200×630）。

## 視覚演出と素材

- 体験は、結果ごとの視覚演出（data/scenes.json）が主で、文章は短い字幕だけにする。
- 素材（assets/scenes/）は利用者がGrok等で生成する。プロンプトには、文字・透かし・実在の人物や生物名・残酷な描写を含めない旨を入れる（scripts/validate.mjs が確認する）。
- 突発的な変化は体験1回につき1回まで、遷移は0.45秒以上。強度1では突発型を使わない。画面の揺れは周期6秒以上の緩やかな動きだけで、点滅は使わない。
- 強度3の素材（巨大な目など）は、強度3を選んだ利用者だけに見せる。
