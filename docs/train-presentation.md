# 連鎖演出の調整

## 2026-11-27 開始時の流れと操作音

フェーズ1（内部station0）は強化なしで直ちに配置を始め、強化未取得でも出発できる。フェーズ2〜6で特殊駒1・区画バフ1・全体バフ1から選択する。再開時も初期強化は表示しない。

配置は空気圧ドア風の0.58秒の専用音、再配置は短い移動音を使う。選択・決定・戻る・表示切替・配置不可・発車も鳴り分ける。ホバーや再描画、音量の連続変更では発音しない。初回ロード中は配置を含む最新1操作だけを1秒以内に再生し、ミュート・停止・期限切れでは破棄する。制作方法は `train-audio.md` を参照。

158テストと本番ビルド成功。390px／1440pxの実ブラウザで、初回盤面タップの配置音が1回だけ再生され、初駅の無強化配置・出発から2駅目の3選択へ進むことを確認。選択・移動・決定・戻る・配置不可・発車の音源再生も確認し、再配置ではドア音を鳴らさない。横はみ出し・JavaScript例外は0。

## 2026-11-27 遊びの幅と評価の整理

- 件数・種類・発生区画数を `summarizeChaos` で共通集計し、途中の状況表示と結果を統一する。上位の段階には種類と広がりが必要で、最大連鎖は補助情報とする。成立駅・区画を固定した全行程の履歴を保持する。
- 通常20件／駅、同種2件／駅、同区画の得点減衰を撤廃する。同じ波の人物競合、完全同一イベントIDの重複防止、1反応内の再発火防止は維持する。大量時も論理判定は切らず、表示を最大2件ずつに分ける。
- 成立後、実際に変わった人物へ短い変化ラベルを付ける。通話・音漏れから画面への集中、起床、姿勢修正などで次の火種を変える。成立時の演出スナップショット、駒の位置、荷物の占有は保持する。
- 通常バフを運行中に蓄積する。同じ効果・範囲・区画は重複取得不可。「ざわめき」を含む6効果から、2駅目以降に特殊駒1・区画1・全体1を毎回提示する。追加ストレス合計48、通路をまたぐ追加波及35を暫定上限とし、既存の局所判定を維持する。区画バフの最大単独値34を活かしつつ併用の余地を残すゲーム用係数で、最適バランスの実証値ではない。
- 「話の輪を作る人」「おすそ分け客」を追加する。新規乗車時だけ、レアリティに応じ1〜3人の関係・行動へ作用し、再配置では再発動しない。
- 次駅に通勤・大きな荷物・静かな乗車・同行客の傾向を予告する。独立した乱数で行動・荷物・同行関係だけを調整し、乗客数・種族・年代・行先の基礎抽選は変えない。実際の駅別統計に基づく分布ではない。
- 演出は既定の「全件しっかり」と任意の「テンポ優先」を設定に集約する。テンポ優先では既出の通常イベントだけ1200msへ短縮し、初見・特殊の見せ場は保つ。短縮時は新たなズームを開始せず、全件を履歴で確認できる。

検証：157テスト・型チェック・本番ビルド成功。390px／1440pxで2駅・計14配置をモデルと照合し、17件・12種類・4区画、段階表示、全履歴、2バフ保持、属性変化、演出設定を確認した。横はみ出し・JavaScript例外は0。自動アクセシビリティ検査は両幅各4画面で違反0（既知の背景ぼかしの色合成誤判定を避けるため検査時のみぼかしを解除）。新特殊駒2種とスマホ結果画面は画像でも確認した。

件数上限撤廃で重くなった特殊イベント判定は、成立必須条件を探索前に調べる。合法な不成立履歴50件の再現ケースで約2338msから1.12msへ改善し、既存の成立条件・探索順を保持した。10シードの単純な合法手選択では6回が終着、4回が配置不能で有限終了したが、最適戦略・全シードの均衡を保証する検証ではない。プロフィール導入前との比較では40シード・5095人の人数／種族／年代／感受性／初期ストレス／行先／乗車駅が一致した。

2026-11-26。配置時の判定・集計は即時に確定し、演出だけをキューで順に表示する。追加配置を待たせず、発車は演出終了後に許可する。省略ボタンは残す。

- イベントは最大2枚ずつ表示。PCは通常4200ms・特殊4800ms、スマホは通常3000ms・特殊3800ms。2枚同時なら450ms加算。イベントなしの波は420ms。キュー混雑と低減モーションで読時間を短縮しない。
- カットインは盤面と別DOMに保持し、次の駒の選択・配置で登場演出を再開しない。メニューと非表示タブでは読時間を止める。
- カメラはトラブルイベント発生時だけ開始する。連鎖のみではズーム・追従を開始しない。盤面のCSS幅を保ち、SVGの視点を1100msで対象駒の中心へ補間する。倍率はPC3倍・スマホ1.4倍。寄り完了後は2200ms以上保持し、自然終了は900msで復帰、省略と再開始は即座に復元する。同じマスの複数人を区別し、乗車移動中は待つ。入力・メニュー・非表示中は補間を止め、現在位置から再開する。スマホは最初から手動拡大状態で、縮小と4扉への移動を使える。
- カットインは内部のスクロール枠ごと画面左外から620msでスライドし、到着時は水平に止める。低減モーション時は移動させない。
- 駒の常時微動は極小のまま。連鎖時に短い溜め・小さな潰れ・復帰・余韻を加える。全61イベントに日常語の一文を用意する。
- 2駅目からの選択肢は特殊駒1・区画バフ1・全体バフ1。区画の効果量を高くし、全体は対象を広げて効果量を下げる。全体バフも無関係な遠方乗客へ配置のたびにストレスを再加算しない。

参考指定の「勇者のくせになまいきだ」について、PlayStation公式候補2ページと説明ページへの接続は403で失敗した。今回、映像の直接比較は未実施。小さな駒の個別反応、溜めと余韻という表現方針を独自実装しており、映像解析済みとは扱わない。SE制作・数値検証は `train-audio.md` に記録する。

検証：147テスト・本番ビルド成功。Chromiumの390px低減モーション／1440px通常設定で、9連続配置と即時ストレス集計の一致、4イベント各1回・スマホ約3.1秒／PC約4.3秒の表示、次駅進行、横はみ出し0、JavaScript例外0を確認。390px通常設定でもメニュー後の同一カットインDOM、省略と再開始を確認。通常設定で見つかったアニメーション復元時のnull代入例外を修正し、両設定で再検証した。

対象追従の検証では、PCの駒幅約112px・画面中央との差約7px、スマホ約94px・約17pxを確認した。ズーム途中のメニュー開閉後も目標倍率へ到達。スライド途中の左側のカードが親枠に切られず描画されることをブラウザの座標・ヒットテストで確認した。
