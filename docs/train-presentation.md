# 連鎖演出の調整

2026-11-26。配置時の判定・集計は即時に確定し、演出だけをキューで順に表示する。追加配置を待たせず、発車は演出終了後に許可する。省略ボタンは残す。

- イベントは最大2枚ずつ表示。通常1枚2600ms・2枚3050ms、特殊を含む場合3500ms・3950ms。イベントなしの波は420ms。キュー混雑と低減モーションで読時間を短縮しない。
- カットインは盤面と別DOMに保持し、次の駒の選択・配置で登場演出を再開しない。メニューと非表示タブでは読時間を止める。
- カメラは自動で盤面サイズを変えず、画面外の反応だけ900msかけて追う。寄りは最大2.5%。入力中と直後は追従しない。スマホは最初から手動拡大状態で、縮小と4扉への移動を使える。
- 駒の常時微動は極小のまま。連鎖時に短い溜め・小さな潰れ・復帰・余韻を加える。全61イベントに日常語の一文を用意する。
- 選択肢は特殊駒1・区画バフ1・全体バフ1。区画の効果量を高くし、全体は対象を広げて効果量を下げる。全体バフも無関係な遠方乗客へ配置のたびにストレスを再加算しない。

参考指定の「勇者のくせになまいきだ」について、PlayStation公式候補2ページと説明ページへの接続は403で失敗した。今回、映像の直接比較は未実施。小さな駒の個別反応、溜めと余韻という表現方針を独自実装しており、映像解析済みとは扱わない。SE制作・数値検証は `train-audio.md` に記録する。

検証：147テスト・本番ビルド成功。Chromiumの390px低減モーション／1440px通常設定で、9連続配置と即時ストレス集計の一致、4イベント各1回・約2.7秒の表示、次駅進行、横はみ出し0、JavaScript例外0を確認。390px通常設定でもメニュー後の同一カットインDOM、省略と再開始を確認。通常設定で見つかったアニメーション復元時のnull代入例外を修正し、両設定で再検証した。
